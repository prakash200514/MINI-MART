#🛒 MiniMart Pro - Supermarket Management System

MiniMart Pro is a web-based supermarket management system developed using HTML, CSS, JavaScript, PHP, and MySQL. The system helps customers browse products, add items to a cart, place orders, and download invoices, while administrators can manage products, stock, categories, users, and orders through a centralized dashboard.
